# DAVA 2

DAVA 2, kişisel siyasi çalışma / temas / takip / proje / not yönetimi için çevrimdışı Android uygulamasıdır.

## İçerik
- Üç hilalli DAVA kimliği
- 4–6 haneli PIN ve sayısal tuş takımı
- Ana ekran özetleri
- Temaslar: arama, kategori, ekleme/düzenleme/silme
- Takip: Açık / Devam / Tamam / Ertelendi, %0–100 tamamlanma, öncelik
- Projeler: Planlama / Devam / Tamam, %0–100 ilerleme
- 11 Tekirdağ ilçesi: etkileşimli şematik harita + ilçe metrikleri
- Notlar
- Ayarlar: PIN değiştirme, AMOLED görünüm, JSON yedek, JSON geri yükleme, CSV dışa aktarma, veri temizleme, Hakkında
- Tamamen yerel SQLite veri tabanı

## Güvenli yeni başlangıç
Bu proje `applicationId = com.dava.app2` kullanır. Eski DAVA APK'sını silmeden yanına kurulabilir.

## GitHub
Yeni boş repo aç: `dava2`. Bu ZIP'in içindeki dosyaları repo köküne yükle. Actions > Build DAVA2 APK çalışır. Başarılı derlemede `DAVA2-debug-apk` artifact'ını indir.
